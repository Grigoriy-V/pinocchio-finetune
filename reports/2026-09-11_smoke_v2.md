The cost rows above count the GPU only. Modal bills CPU and memory
beside it, and the functions reserved 8 cores and 64 GiB — $0.88/h, +40 %
on an A100-40 (the human's bill, 2026-09-12: $4.75 GPU, $1.16 memory,
$0.86 CPU before the v1 run had finished). The reservations are now 2
cores and 16 GiB for training; the v1 run's true cost is ~$8.

What it settles:

- **B (bf16 instead of NF4) changes nothing in speed**: 53.7 against
  50.5 s for the same tokens per step. Dequantisation was not the
  ceiling; with the card and the quantisation both ruled out, what is
  left of the research's list is the attention path without a flash
  kernel (26 sliding-window layers with a mask, 4 global layers with
  head_dim 512), quadratic in the 5k-token samples. That is now the
  working hypothesis, still to be measured directly.
- **A (one sample per run) is worth exactly its arithmetic**: a run's
  sample is the same ~5.2k tokens as a call's, so a step costs the same,
  and there are 3.4× fewer of them. Two epochs in under an hour.
- **A + B fits an A100-40** with 12 GB to spare at 5.8k tokens.
- 28 runs left the v2 set (an assistant message with text beside a
  call); 232 remain, 6k fewer target tokens than v1's 782 samples,
  because each target is now seen once per epoch instead of once per
  call that followed it.

What is not settled: whether a model trained on run sequences measures
the same as one trained per call — the history segments are rendered as
stored turns, the first model turn gets the empty thought channel
inserted, and every assistant segment of a run is a target once. The
held-out families answer that, after v1's own measurement.
